# 🐦‍⬛ Crow Detailing | Tienda de Productos Premium

Sitio web de e-commerce para **Crow Detailing**, tienda especializada en productos de detailing profesional para autos y motos. Ubicada en Villa Urquiza, CABA, Argentina.



## 📋 Descripción

Crow Detailing ofrece productos premium para el cuidado y estética vehicular: shampoos pH neutro, pulidores, recubrimientos cerámicos, ceras y accesorios. Este sitio fue construido como catálogo web con formulario de contacto integrado.



## 🗂️ Estructura del proyecto

```
crowdetailing/
├── index.html      → Estructura HTML semántica principal
├── styles.css      → Estilos CSS externos (responsive)
└── README.md       → Este archivo
```



## 🧱 Secciones del sitio

- **Header** — Logo, navegación fija con efecto scroll, botón de contacto
- **Hero (Inicio)** — Banner principal con título, estadísticas y video embed
- **Servicios** — Barra de servicios: Lavado, Pulido, Cerámica, Brillo
- **Productos** — Cards con filtro por categoría (Flexbox)
- **Reseñas** — Opiniones de clientes (CSS Grid)
- **Contacto** — Formulario con Formspree + mapa embed
- **Footer** — Links, categorías, redes sociales y datos de la tienda



## ✅ Requisitos técnicos implementados

| Requisito | Detalle |
|---|---|
| HTML semántico | header, nav, main, section, footer |
| Formulario de contacto | Nombre, email, mensaje — integrado con Formspree |
| CSS externo | styles.css con estilos de header, footer y nav |
| Google Fonts | Bebas Neue, Rajdhani, Inter |
| Background decorativo | Gradiente radial en hero, fondos en secciones |
| Flexbox | Sección Productos en cards responsivas |
| CSS Grid | Sección Reseñas con distribución en grilla |
| Media Queries | Adaptación a tablet (1024px), mobile (768px) y mobile chico (480px) |
| Multimedia | Video embed (YouTube) en hero, iframe de Google Maps en contacto |
| Navegación | Lista desordenada con enlaces internos (Inicio, Productos, Reseñas, Contacto) |



## 🎨 Identidad visual

- **Colores**: Negro #0a0a0f + Violeta #7c3aed + Blanco
- **Tipografías**: Bebas Neue (títulos), Rajdhani (subtítulos), Inter (cuerpo)
- **Estilo**: Dark theme premium, inspirado en la marca real de Crow Detailing



## 🚀 Cómo usar

1. Clonar o descargar el repositorio
2. Abrir index.html en el navegador
3. Para activar el formulario: reemplazar el endpoint de Formspree en el action del form con tu propio ID
