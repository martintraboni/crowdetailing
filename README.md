# 🐦‍⬛ Crow Detailing — Catálogo Web de Productos Premium

Sitio web de catálogo digital desarrollado para **Crow Detailing**, marca especializada en productos de detailing profesional para autos y motos.
Ubicada en Villa Urquiza, CABA, Argentina.

---

## 📋 Descripción

Crow Detailing ofrece productos premium para el cuidado y estética vehicular: shampoos pH neutro, pulidores, recubrimientos cerámicos, ceras, acondicionadores y accesorios.

El proyecto fue desarrollado como un **catálogo web moderno**, con diseño responsive, organización de productos por categorías y formulario de contacto integrado.

---

## 🗂️ Estructura del proyecto

```text
crowdetailing/
│
├── index.html      → Estructura HTML semántica principal
├── styles.css      → Estilos, diseño responsive y animaciones
├── script.js       → Funcionalidades e interacción del sitio
├── imágenes/       → Recursos gráficos y productos del catálogo
└── README.md       → Documentación del proyecto
```

## 🧱 Secciones del sitio

### Header

* Logo de la marca
* Navegación fija con efecto al hacer scroll
* Botón de contacto

### Hero (Inicio)

* Presentación principal de la marca
* Estadísticas del servicio
* Video integrado

### Servicios

* Lavado
* Pulido
* Cerámica
* Protección y brillo

### Productos

* Catálogo organizado mediante tarjetas
* Filtros por categorías
* Diseño adaptable con Flexbox

### Reseñas

* Opiniones de clientes
* Distribución mediante CSS Grid

### Contacto

* Formulario de contacto integrado con Formspree
* Ubicación mediante Google Maps
* Información de la tienda

### Footer

* Redes sociales
* Categorías
* Datos de contacto

# ✅ Requisitos técnicos implementados

| Requisito              | Implementación                                            |
| ---------------------- | --------------------------------------------------------- |
| HTML semántico         | Uso de `header`, `nav`, `main`, `section` y `footer`      |
| Formulario de contacto | Campos de nombre, email y mensaje integrado con Formspree |
| CSS externo            | Archivo `styles.css` con diseño completo                  |
| JavaScript             | Interacciones y funcionalidades del sitio                 |
| Google Fonts           | Bebas Neue, Rajdhani e Inter                              |
| Diseño responsive      | Adaptación para desktop, tablet y dispositivos móviles    |
| Flexbox                | Organización de tarjetas de productos                     |
| CSS Grid               | Sección de reseñas                                        |
| Multimedia             | Video YouTube e iframe de Google Maps                     |
| Navegación interna     | Enlaces hacia Inicio, Productos, Reseñas y Contacto       |

---

# 🚀 Cómo utilizar

1. Clonar o descargar el repositorio.

2. Abrir el archivo:

```text
index.html
```

en cualquier navegador.

3. Para utilizar el formulario de contacto, configurar el endpoint propio de Formspree dentro del atributo `action` del formulario.
